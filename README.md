# CS Bihorul Beiuș

Site de prezentare pentru echipa de fotbal CS Bihorul Beiuș, din județul Bihor, orașul Beiuș, înființat în 1921, care evoluează în Liga a III-a.

🌐 **Site live:** https://rarespop13.github.io/

## Ce conține

- **Pagina principală** cu video în fundal, logo 3D care se înclină la atingere sau la mișcarea cursorului și istoria clubului sub formă de cronologie
- **Stadion**: prezentarea stadionului
- **Galerie**: fotografii cu echipa
- **Formular de contact** (trimis prin [FormSubmit](https://formsubmit.co))
- **Temă deschisă / întunecată**, salvată între vizite
- **Design responsive**, cu meniu hamburger pe telefon
- Poze care se măresc la apăsare

## Rulare locală

Nu are nevoie de instalare. Descarci proiectul și deschizi `index.html` în browser.
Pentru rezultate corecte la video, e mai bine să-l pornești printr-un server local, de exemplu cu extensia *Live Server* din VS Code.
